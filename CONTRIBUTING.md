# Contributing

Issues and pull requests are welcome.

- Use Node.js 20 or newer and run `npm install` once.
- Before opening a pull request, run `npm test`, `npm run typecheck` and `npm run test:visual`; all must pass.
- Keep code identifiers in English. On-screen text comes from project data, never from hard-coded strings.
- A new scene type needs a schema (with length limits), a component, an entry in `EXAMPLES` and a visual snapshot.
- Keep pull requests small and focused, and describe what changed and why.
